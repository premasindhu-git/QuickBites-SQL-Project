# QuickBites – SQL Food Delivery Database Project

## 📌 Project Overview
QuickBites is a food delivery database project developed using MySQL. It simulates a food delivery application like Swiggy or Zomato and demonstrates how SQL can be used to manage customer information, restaurant details, orders, delivery partners, and menu items.

## 🎯 Project Objectives
- Design and manage a relational database.
- Retrieve and filter data using SQL queries.
- Analyze order details and revenue.
- Combine data from multiple tables using JOINs.
- Generate meaningful business reports using SQL.

## 🛠️ Technologies Used
- **Database:** MySQL
- **Query Language:** SQL
- **Concepts:** DDL, DML, SELECT, WHERE, GROUP BY, Aggregate Functions, JOINs, Subqueries, and Views.

## 🗂️ Database Tables
The database consists of five main tables:

1. **Customers** – Stores customer names, cities, and join dates.
2. **Restaurants** – Stores restaurant names, cuisine types, and ratings.
3. **Orders** – Stores order dates, customer IDs, restaurant IDs, delivery partner IDs, amounts, and order statuses.
4. **Delivery Partners** – Stores delivery partner names, phone numbers, and vehicle types.
5. **Menu Items** – Stores menu item names, prices, and associated restaurant IDs.

## 🔍 SQL Concepts Implemented

- **DDL:** Creating database tables using `CREATE TABLE`.
- **DML:** Inserting data using `INSERT INTO`.
- **Filtering and Sorting:** Using `WHERE`, `AND`, `OR`, and `ORDER BY`.
- **Aggregate Functions:** Using `COUNT()`, `SUM()`, `AVG()`, `MAX()`, and `MIN()`.
- **GROUP BY:** Analyzing customers by city and calculating revenue.
- **JOINs:** Combining customer, order, restaurant, and delivery partner data.
- **Subqueries:** Identifying above-average orders and customers with cancelled orders.
- **Views:** Creating reusable reports using `CREATE VIEW`.
- **Business Analysis:** Finding top-spending customers, city-wise revenue, and customers who have never cancelled an order.

## 📊 Key Business Insights
The project demonstrates how SQL can help answer business questions such as:

- Which restaurants have high ratings?
- How many customers belong to each city?
- What is the total revenue from delivered orders?
- Which customers spend the most?
- Which orders are above the average order value?
- How much revenue is generated by each city?
